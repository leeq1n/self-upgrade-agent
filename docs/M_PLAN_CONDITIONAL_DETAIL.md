## Self-audit 4-condition check

Before any major commit / decision, agent
should ask itself:

| Q | Question | YES → trigger |
|---|---|---|
| Q1 | Agent 不确定 plan OR goals? | M-n 21 (ask/infer/guess) + replan |
| Q2 | Plan 混乱 OR multiple parts conflict? | M-n 12 (terminology) + replan |
| Q3 | 重大调整 (new M-n / P-n / 项目 pivot)? | Per M-n 20 (agent-discoverability) + replan |
| Q4 | User explicit "先 做规划"? | Replan (highest priority) |

If ANY = YES → replan (per M-n 22 3W1H-first).
If ALL = NO → continue per M-n 24.

## When to plan vs when to continue

### Plan first (uncertain / 混乱 / 重大调整)

- New project or major pivot.
- User explicitly asks for planning.
- Multiple M-n / P-n / R-n changes conflict.
- Agent can't articulate current PLAN in
  1 sentence.
- Per M-n 23 trigger met (10+ commits OR
  1+ hour).

### Continue (clear / feasible / aligned)

- PLAN is clear (1-sentence goal +
  sub-tasks).
- Per M-n 24: commit + continue.
- No major conflicts detected.
- User has implicit OR explicit continuation
  directive.
