## The revised architecture (per user)

Per user 2026-07-14 final insight: instead of
**manually maintaining** 2 projects (SUA graph +
skill-v2 flat), use a **converter tool** that
**on-demand** exports the SUA graph as a flat
skill for any target project.

### Before (per c53) — manual 2-project

```
hermes-root/
├── self-upgrade-agent/   # graph (manually maintained)
└── agent-onboarding-v2/  # flat (manually synced)
```

Problem: manual sync = drift + extra work.

### After (per this commit) — graph + converter

```
hermes-root/
├── self-upgrade-agent/
│   ├── docs/             # graph (single source of truth)
│   └── tools/
│       └── graph_to_skill.py   # NEW: converter
│
└── (NO skill-v2 project)  # skill is generated output
```

Benefit: **single source of truth** (SUA graph) +
**on-demand generation** (per project, per export).

## How the converter works

### Input

- SUA docs (graph view):
  - `docs/PRINCIPLES.md` + `PRINCIPLES_DETAIL.md`
  - `docs/OPERATING_RULES.md` + `OPERATING_RULES_DETAIL.md`
  - `docs/MCP_TOOLS.md`
  - `docs/RECURSIVE_DECOMPOSITION.md` + others

### Output

A skill package (per Hermes skill format):
- `SKILL.md` (entry point, ≤ 100 lines, L0 layer)
- `references/` (L1 + L2 detail, sequential)
- `assets/` (templates, examples — if needed)
- `scripts/` (helper scripts — if needed)

### Generation flow

```
$ python .hermes/scripts/graph_to_skill.py \\
    --source self-upgrade-agent/docs/ \\
    --target ./exported-skill/ \\
    --name "agent-onboarding" \\
    --description "..." \\
    --tags "..."

# Reads SUA graph, traverses cross-refs,
# produces SKILL.md + references/*.md
```

## Why this is better than 2-project (per c53)

| Aspect | 2-project (c53) | Graph + converter (this) |
|---|---|---|
| Source of truth | 2 copies (graph + flat) | 1 (graph) |
| Sync effort | manual, ongoing | none (generated) |
| Drift risk | high (2 copies diverge) | low (single source) |
| Exportability | per project (rewrite) | per project (one command) |
| Maintenance | high (update both) | low (update graph only) |
| Per P7 奥卡姆 | violates (redundant) | satisfies (no redundancy) |
| Per P11 摘要+引用 | violates (must sync) | satisfies (auto-generated) |
| Per P13 no orphan | satisfies (manual refs) | satisfies (auto-generated refs) |

**Decision per "选哪个最优" (P7 奥卡姆)**: graph +
converter is optimal per P7 + P11 + P13.
